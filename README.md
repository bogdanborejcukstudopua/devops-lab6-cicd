# Лабораторна робота №6: CI/CD Pipeline (GitHub Actions)

Цей репозиторій містить автоматизований CI/CD pipeline для Flask API сервісу, який розраховує перехідні процеси в RLC-контурі.

## Варіант
**Непарний номер у списку (№5):** Автоматична збірка Docker-образу + додатковий етап тестування через `unittest`.
